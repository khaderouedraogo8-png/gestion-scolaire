# Captures d'écran UI

Générées automatiquement pour revue visuelle (Claude, équipe, etc.).

```powershell
# Depuis la racine du projet
.\scripts\reset-admin.ps1 -Target native
cd frontend
npm run screenshots
```

Fichiers PNG dans ce dossier (`00-login.png` … `15-eleves-mobile.png`).
